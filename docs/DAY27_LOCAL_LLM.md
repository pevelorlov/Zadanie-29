# День 27 — интеграция локальной LLM в приложение

## Что реализовано

Веб-приложение обращается к OpenAI-совместимому HTTP API LM Studio и показывает ответ в существующем интерфейсе чата. В настройках диалога можно выбрать:

- `ornith-1.5-9b` — локальная модель в LM Studio, вариант по умолчанию;
- `deepseek-v4-flash` — облачная модель DeepSeek;
- `deepseek-v4-pro` — облачная модель DeepSeek.

Скрытого переключения на облачную модель нет: если выбрана локальная модель, а LM Studio недоступна, приложение показывает ошибку подключения.

## Параметры локальной модели

- URL: `http://127.0.0.1:1234/v1`;
- контекстное окно: `32 768` токенов;
- максимальная длина ответа по умолчанию: `4 096` токенов;
- максимальное ожидание одного ответа: `1 800` секунд (30 минут);
- модель: `ornith-1.5-9b`.

URL, модель и время ожидания можно изменить в `.env` через `LM_STUDIO_BASE_URL`,
`LM_STUDIO_MODEL` и `LM_STUDIO_TIMEOUT`. Долгая локальная генерация не считается
ошибкой, пока не истекло заданное время ожидания.

Ornith является reasoning-моделью: скрытое рассуждение входит в общий лимит
генерации. Поэтому служебные JSON-вызовы приложения используют поддерживаемый
LM Studio формат `json_schema` и резерв не менее `4 096` токенов независимо от
коротких лимитов классификаторов. Лимит обычного ответа из выбранного пресета
при этом не изменяется.

Интерфейс отдельно показывает лимит модели, выбранной для следующего запроса. Показатель «Контекст последнего вызова» относится к модели, которая фактически обработала предыдущее сообщение, поэтому в старом диалоге он может показывать DeepSeek до первого локального запроса.

## Запуск

1. В LM Studio загрузить `ornith-1.5-9b` и запустить Local Server.
2. Запустить `run.bat`.
3. В настройках чата выбрать локальную или облачную модель.
4. Отправить сообщение и получить ответ в интерфейсе.

Для DeepSeek дополнительно нужен `DEEPSEEK_API_KEY` в `.env`. Для локальной модели ключ и облачный API не нужны.

## Живая проверка

При запущенном сервере LM Studio выполнить:

```powershell
.venv\Scripts\python.exe scripts\day27_live_smoke.py
```

Скрипт использует временное хранилище и проверяет полный путь: Flask API → маршрутизатор модели → LM Studio → сообщение ассистента.
